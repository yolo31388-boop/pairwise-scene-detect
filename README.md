# pairwise-scene-detect

同一场戏切了三个机位，检测把每个机位切换都当成广告，慢动作片段整段没切，闪白转场后插入点晚了五秒：镜头边界只看直方图差异，同场景换机位被误判为切点；渐变转场按单帧阈值检测，淡入淡出整段漏掉；闪白和曝光突变被当成硬切，转场前后各多切一刀；相机快速摇移被当成镜头切换，长镜头被切碎；慢动作素材帧间差异小，阈值过高导致整段并成一场；重复帧和冻结帧没有去重，静止画面被算成连续镜头；时间码和帧率不一致，25fps 素材按 30fps 解析，切点偏移；B 帧重排序后解码顺序和时间戳错位，边界落在错误帧；HDR 和 SDR 混剪时直方图 bin 范围不同，同一场景被判成两段；音频波形和画面对齐用的是文件起点，片头黑场导致广告插入点整体后移；最短镜头长度过滤把快切广告整段删掉；置信度阈值按全片固定，暗场和夜景全部漏检；检测结果按文件缓存，替换素材后仍用旧切点。media/scene_detect.py 是核心，tests/test_scene_detect.py 15个红。要修的是：机位区分；渐变检测；闪光抑制；运动补偿；慢动作阈值；重复帧；时间码；B 帧顺序；HDR 归一；音频对齐；最短镜头；自适应阈值；缓存失效。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
